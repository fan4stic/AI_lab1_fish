# Model Card: FishGrow Regressor

**Паспорт модели.** Краткая справка о назначении, обучении, метриках и ограничениях модели предсказания массы рыбы.

---

## 1. Назначение

**Тип задачи:** регрессия.  
**Целевая переменная:** `Weight` — масса рыбы, граммы.  
**Входные признаки:**

- `Length3` — длина рыбы, мм (числовой);
- `Height` — высота, мм (числовой);
- `Width` — ширина, мм (числовой);
- `Species` — вид рыбы (категориальный, 7 значений).

**Область применения:** учебный прототип для оценки массы рыбы по морфологическим признакам в рамках дисциплины «Введение в искусственный интеллект».

**Что модель не делает:** не учитывает сезон, возраст рыбы, состояние (икра, жирность); не предназначена для применения в производственной среде без дополнительной валидации.

---

## 2. Модель

**Алгоритм:** `HistGradientBoostingRegressor` из scikit-learn (гистограммный градиентный бустинг).  
**Обоснование выбора:** лучшая метрика CV MSE среди 6 экспериментов E0–E4 (см. `runs/summary.csv`).

**Гиперпараметры (выбраны через GridSearchCV с 5-кратной CV по GroupKFold):**

- `max_iter`, `learning_rate`, `max_depth` — подбирались из небольшой сетки;
- `random_state = 42`.

**Преобразование целевой переменной:** `log1p(Weight)` при обучении, `expm1` при предсказании, через `TransformedTargetRegressor`. Обоснование — сильная правосторонняя асимметрия распределения веса.

**Предобработка (в составе Pipeline):**

- числовые признаки: `SimpleImputer(strategy="median")` + `StandardScaler`;
- категориальные: `SimpleImputer(strategy="most_frequent")` + `OneHotEncoder(handle_unknown="ignore")`.

## 6. Ограничения и рекомендации

**Ограничения:**

- Мало данных по крупным видам (Pike — 2 объекта в тесте);
- `log1p`-преобразование систематически занижает крупные прогнозы (Pike, большие Bream);
- отсутствуют признаки сезона, возраста и состояния рыбы;
- тестовая выборка всего 23 объекта, поэтому метрики имеют заметный доверительный интервал;
- `Species` критичен для качества: без него модель деградирует до R² = −0.26 (см. E4).

**Рекомендации по применению:**

- применять только к рыбам тех видов, которые были в обучающем наборе (Bream, Parkki, Perch, Pike, Roach, Smelt, Whitefish);
- для масс > 1000 г ожидать систематическую недооценку;
- перед использованием в продуктиве — расширить обучающий набор и пересмотреть преобразование целевой переменной (см. следующий эксперимент в отчёте).

**Что нельзя делать:**

- применять модель к другим видам рыб без переобучения;
- использовать для точных коммерческих расчётов без дополнительной валидации;
- считать прогнозы для рыб с морфологией, сильно отличающейся от обучающего набора.

## 7. Следующий эксперимент

По результатам анализа ошибок (см. раздел 5 отчёта) предлагается:

- Обучить отдельные модели для «мелких» (Smelt, Roach, Parkki) и «крупных» (Pike, Bream, Perch, Whitefish) видов.
- Ожидаемый эффект: MAE по Pike < 200 г, MAE по Bream < 70 г, общий R² в диапазоне 0.92–0.94.

Альтернатива — bias correction при обратном преобразовании `expm1` (добавление среднего остатка на train).
